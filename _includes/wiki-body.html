[[slug|label]] internal wiki link -> label ((text)) footnote -> n + a numbered note in the Notes list, per entry Carried forward from wiki-bundle/ds/pages/wiki.html, which did the same two transforms in the browser. Doing them at build time instead means the finished prose is in the HTML source, so the site's own search.js — which walks
— indexes wiki entries for free, and the page still reads correctly with JavaScript off. Usage, from _layouts/wiki-entry.html: {% capture wk_raw %}{{ content }}{% endcapture %} {% include wiki-body.html html=wk_raw %} Outputs the
and, if the entry has any footnotes, the Notes section after it. Authoring rules this relies on: * Every [[slug|…]] must name a slug that exists as an entry page. An unknown slug will not be matched and its trailing ]] will still close, producing visibly broken markup — which is the point: it fails loudly at build rather than silently linking nowhere. * A slug may name a section OR an app. An app slug resolves to that app's first section. Slugs are therefore globally unique across the whole wiki, sections and apps together. * `]]` is reserved. It cannot appear in body copy for any other reason. * Links are compiled BEFORE footnotes, so a footnote may contain a [[link]] but a link label may not contain a ((footnote)). ============================================================================= {%- endcomment -%} {%- assign wk_entries = site.pages | where_exp: "p", "p.layout == 'wiki-entry'" | sort: "order" -%} {%- assign wk_apps = site.pages | where_exp: "p", "p.layout == 'wiki-app'" | sort: "order" -%} {%- assign out = include.html -%} {%- comment -%} ---- pass 1: internal links ---- Sections first, then apps. An app slug resolves to that app's FIRST section, so [[gaffer-iq|Gaffer IQ]] keeps working and lands the reader on prose rather than on a redirect. Sections are matched first because a section slug is the more specific target; the two spaces do not overlap, so the order is a statement of intent rather than a tie-breaker. {%- endcomment -%} {%- for e in wk_entries -%} {%- assign wk_pa = wk_apps | where: "slug", e.parent | first -%} {%- assign wk_lk_kind = e.kind | default: wk_pa.kind -%} {%- capture wk_needle -%}[[{{ e.slug }}|{%- endcapture -%} {%- capture wk_tag -%}{%- endcapture -%} {%- assign out = out | replace: wk_needle, wk_tag -%} {%- endfor -%} {%- for a in wk_apps -%} {%- assign wk_as = wk_entries | where: "parent", a.slug -%} {%- assign wk_af = wk_as | first -%} {%- if wk_af -%} {%- capture wk_needle -%}[[{{ a.slug }}|{%- endcapture -%} {%- capture wk_tag -%}{%- endcapture -%} {%- assign out = out | replace: wk_needle, wk_tag -%} {%- endif -%} {%- endfor -%} {%- assign out = out | replace: "]]", "" -%} {%- comment -%} ---- pass 2: footnotes ---- {%- endcomment -%} {%- assign wk_chunks = out | split: "((" -%} {%- assign wk_body = wk_chunks[0] -%} {%- assign wk_notes = "" -%} {%- if wk_chunks.size > 1 -%} {%- for c in wk_chunks offset: 1 -%} {%- assign n = forloop.index -%} {%- assign note = c | split: "))" | first -%} {%- assign cut = note | size | plus: 2 -%} {%- assign rest = c | slice: cut, 200000 -%} {%- capture wk_marker -%}{{ n }}{%- endcapture -%} {%- assign wk_body = wk_body | append: wk_marker | append: rest -%} {%- capture wk_li -%}
