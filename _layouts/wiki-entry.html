--- layout: default --- {%- comment -%} ============================================================================= wiki-entry.html — the shell around every /projects/wiki// write-up. Nests inside _layouts/default.html, so the header, nav, search, footer, theme toggle, paper grain, type scale and reveal animations all come from the main site with nothing restated here. An entry page therefore carries front matter plus body prose and nothing else. Front matter an entry page declares: layout: wiki-entry (required) slug: gaffer-iq (must match the folder name) order: 10 (sort position across the whole wiki) group: Tools (rail grouping; the string is the label) title: Gaffer IQ kind: Application (shown in the meta strip and hover peek) revised: 2026-08-25 steward: Josh Bailey lede: one italic sentence status: draft (optional — renders the draft banner) app_url: /projects/apps/gaffer-iq/ (optional — the Launch button) info: mapping of key/value rows for the infobox (optional) Everything derived below — the rail index, numbering, backlinks, pager — is read from those pages at build time.
