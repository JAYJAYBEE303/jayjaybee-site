Why a second style of view

I wanted to provide a different style of view; instead of providing calculated metrics for what lies ahead, I wanted to provide a page that displays true historical data which relies less on the engine. This gives the user a more open-to-interpretation perspective on fixtures, in the case that they don't fully trust the engine providing the guessing for them — the [[matchup-idea-and-approach|Matchups]] page won't suit everyone, nor will everyone trust the engine's guessing and suggestions, so to expand the target audience I realised I needed a way to allow the user to have a more manual way of reading the game.

How it is sourced

To do this, I chose to provide more rigid information that focuses on historical data that doesn't go through any processing change, and outputs useful data exactly as it was fetched. The understat.com API had everything needed to make this work effectively, meaning minimal data from the FPL API was needed to fill this area of the site.
