An EA FC card is a list of two-digit numbers. What a player feels like under your thumb is something else: the numbers after chemistry has been applied, after PlayStyles have moved the curves, and after the game's own non-linear scaling has decided that the gap between 84 and 88 is not the same size as the gap between 88 and 92.

This calculator models that second thing. It exists because I wanted the version of it I could not find.

What it models

  • Chemistry — the actual applied boosts at each chemistry level, not the headline figure.
  • PlayStyles — including the plus tiers, which change behaviour rather than just adding points.
  • The underlying curves — the diminishing returns the game runs that make raw stat comparison misleading at the top of the range.((These were derived from in-game testing across several rounds of tuning, not from any published source. They are a model of the game's behaviour, not a reading of its code.))

How it is built

One file, no build

Around 2,500 lines of HTML and vanilla JavaScript in a single document. No bundler, no framework, no build step — which means the thing that ships is the thing I edited, and there is no toolchain to rot between one game cycle and the next.

Two layouts

Mobile gets a single focused read: one player, the numbers that matter, nothing else. Desktop gets the comparison view, because comparison is what people actually open a calculator for and it needs horizontal room. The UI was rebuilt in Tailwind once the maths had stopped moving — deliberately in that order, so styling effort was not spent on layouts the formulas were about to invalidate.

What it taught me

More about state management in plain JavaScript than any framework tutorial has. With no framework holding the state, every stale-value bug is yours, visible, and instructive.

It also set the pattern the rest of the work follows: model the thing properly first, argue with the model against reality, and only then make it look like something. [[gaffer-iq|Gaffer IQ]] was built the same way round.
